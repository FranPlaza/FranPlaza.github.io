A Transformer combines the same history differently

Same history and target. A different way to combine information across days.

Current temporal tutorial · 2,257 trainable parameters versus 1,297 for LSTM · One fixed, small configuration

duration_seconds: 120

Main idea: Attention combines the same observed days differently from an LSTM state.

Explain: At minute 50, show the current temporal notebook’s Transformer. Each day is projected to 16 features and receives a learned 16-value day-position embedding. Two attention heads, each with key dimension 8, combine positions. Residual additions and layer normalization surround attention and the 16-to-16 feed-forward sublayer. Average pooling and a sigmoid produce the weekly probability.

Transition: At minute 52, compare the probabilities under the unchanged evaluation.

Backup: The diagram matches the explicit Transformer definition in scripts/linear_tutorial_sources/temporal.json. Projection: 64 parameters, learned positions: 480, attention: 1,088, two normalizations: 64, feed-forward: 544, output: 17. Total: 2,257 trainable parameters versus 1,297 for LSTM. No dropout is applied. All input positions precede the origin, so within-history attention does not expose the target. Capacity differs between architectures. Attention weights alone do not establish causation.

Appendix · the LSTM steps

inputs = keras.Input(shape=(30, 3))
state = keras.layers.LSTM(16)(inputs)
probability = keras.layers.Dense(1, activation="sigmoid")(state)
model_lstm = keras.Model(inputs, probability)
model_lstm.compile(optimizer="adam", loss="binary_crossentropy")
history_lstm = model_lstm.fit(
    X_train, y_train, validation_data=(X_val, y_val),
    epochs=20, batch_size=64, callbacks=[stopping_lstm], shuffle=False)
p_lstm = model_lstm.predict(X_val).ravel()
brier = np.mean((p_lstm - y_val) ** 2)
