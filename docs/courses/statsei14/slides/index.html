Main idea: A generator learns to produce samples under a training objective.

Explain: Follow z into G and stop at the generated sample x̃ = G(z): this is the output we want to obtain. Explain: Begin with the catalogue: event times, locations and magnitudes. The study fits temporal ETAS across the area and shares its parameters across 1° × 1° grid cells. A Transformer combines the same history differently

Same history and target. A different way to combine information across days.

Current temporal tutorial · 2,257 trainable parameters versus 1,297 for LSTM · One fixed, small configuration

Main idea: Attention combines the same observed days differently from an LSTM state.

Explain: If the pace allows a brief comparison, show the temporal notebook’s Transformer using prepared outputs. Each day is projected to 16 features and receives a learned 16-value day-position embedding. Two attention heads, each with key dimension 8, combine positions. Residual additions and layer normalization surround attention and the 16-to-16 feed-forward sublayer. Average pooling and a sigmoid produce the weekly probability.

Transition: Compare the probabilities under the unchanged evaluation.

Backup: The Transformer first projects each day and adds a learned position vector. Projection: 64 parameters, learned positions: 480, attention: 1,088, two normalizations: 64, feed-forward: 544, output: 17. Total: 2,257 trainable parameters versus 1,297 for LSTM. No dropout is applied. All input positions precede the origin, so within-history attention does not expose the target. Capacity differs between architectures. Attention weights alone do not establish causation.
